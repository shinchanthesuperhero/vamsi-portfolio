# Vamsi Devarinti Portfolio

This is a static website. It has no build step; Netlify serves `index.html` and the files in this repository directly.

## Publish with Netlify

1. Push this repository to GitHub.
2. In Netlify, choose **Add new site → Import an existing project** and connect this GitHub repository.
3. Leave the build command empty. Netlify reads `netlify.toml` and publishes the repository root.
4. Choose **Deploy site**. Netlify will provide a public URL and redeploy whenever changes are pushed to `main`.

You can also use Netlify Drop to manually upload the site files for a one-time deployment.
